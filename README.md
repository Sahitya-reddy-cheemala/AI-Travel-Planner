# 🌍 Enhanced Travel Itinerary Planner

A powerful AI-based travel planning assistant that creates personalized multi-day travel itineraries using LangChain, LangGraph, Groq (LLM), Gradio, and live APIs (weather + events).

---

## 🚀 Overview

Enhanced Travel Itinerary Planner is an intelligent AI travel assistant that generates customized, multi-day itineraries based on user preferences such as budget, interests, dietary needs, accessibility requirements, and travel dates.

The application integrates:

- Groq LLaMA3-70B (LLM)
- OpenWeatherMap API (Live Weather)
- Ticketmaster Discovery API (Local Events)
- LangGraph Workflow Engine
- Gradio Interactive UI

---

## 🔥 Features

- ✅ Multi-day, city-specific itinerary generator  
- ✅ LLM-powered activity suggestions (Groq - LLaMA3-70B)  
- ✅ Live weather data integration  
- ✅ Local events discovery  
- ✅ Budget-based cost estimation  
- ✅ Dietary & accessibility considerations  
- ✅ Interactive Gradio interface  
- ✅ Modular LangGraph workflow
